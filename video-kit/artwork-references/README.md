# Artwork references

Ces huit couvertures proviennent des URL de couverture actuellement enregistrées dans le catalogue canonique Manga Wave. `manifest.json` conserve l’ID canonique, la route produit, les métadonnées et l’URL source.

Elles servent à préparer le montage et à identifier les plans. Leur présence dans le produit ne constitue pas une licence publicitaire ; vérifier les droits avant une diffusion sponsorisée.

Régénération :

```bash
node scripts/video/export-artwork-references.mjs
```
